# Fluffy logo asset

Tool: built-in imagegen.
Output: `assets/logo-fluffy.png`.
Input: the user's yellow furry logo on a navy background.

## Prompt

Use case: background-extraction. Edit target: supplied yellow furry abstract logo. Create a production website transparent PNG asset. Remove ONLY the navy background to genuine alpha transparency. Preserve the exact logo silhouette, orientation, proportions, bright lemon yellow color, detailed long silky individual hairs, directional grooming, soft fluffy irregular outline, lighting and shadows within the fur. Do not turn it into plastic, felt, dots or particles. No ground plane, no shadow outside the object, no text, no background color or checkerboard baked in. Center the complete unchanged furry object in a square canvas with about 7% transparent margin on each side; keep every fine edge hair. The result will be used as a high resolution texture animated on a website.
